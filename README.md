## Project Overview

Design and develop a visually stunning, modern, premium, and fully responsive personal portfolio website for **Iman Zahra**, a Digital Artist, Creative Designer, Content Creator, and Web Developer, operating under the creative brand **aestheticsbyiz**.

The website should communicate creativity, professionalism, versatility, and innovation. It should establish Iman as a multidisciplinary creative professional who combines design, technology, and visual storytelling to help businesses build memorable digital identities.

The overall aesthetic should combine **minimalist elegance with bold creative expression**, featuring sophisticated typography, clean layouts, refined animations, and visually immersive project presentations.

The website should feel like a premium creative studio portfolio rather than a conventional student portfolio.

## 10. VISUAL DESIGN DIRECTION

**Overall aesthetic: Minimalist Elegance Meets Bold Creativity.**

The website should feel premium, modern, artistic, and professionally curated.

### Color Palette

Use a sophisticated neutral foundation:

- Warm Off-White: #F7F6F2
- Soft Cream: #EEECE5
- Charcoal Black: #171717
- Muted Gray: #777777
- Accent Taupe: #B5A99A

Use occasional bold accent colors only when they complement the featured project visuals.

### Typography

Use a combination of:
- Elegant editorial typography for large headings.
- Modern sans-serif typography for body text.
- Bold display typography for hero statements.

Suggested fonts:
- Playfair Display.
- DM Sans.
- Manrope.
- Space Grotesk.

Maintain excellent readability and typographic hierarchy.

### Layout

- Spacious layouts.
- Large typography.
- Generous white space.
- Asymmetric editorial compositions.
- High-quality imagery.
- Consistent spacing.
- Clean navigation.
- Premium project cards.

### Animations

Use tasteful, performance-friendly animations:
- Smooth scrolling.
- Fade-in effects.
- Subtle parallax.
- Animated typography.
- Image reveal transitions.
- Hover interactions.
- Smooth page transitions.

Avoid excessive animation, unnecessary visual clutter, and distracting effects.
